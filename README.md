# AI_Project - Sistema de Recomendación con GitHub Copilot

## Descripción
Actividad formativa para explorar herramientas y tendencias emergentes de Inteligencia Artificial utilizando GitHub Copilot en Visual Studio Code.

## Contenido del Repositorio
- `recommendation_system.py`: Script en Python que implementa un modelo de clasificación KNN (K-Nearest Neighbors) para recomendación y predicción.
- `README.md`: Documentación del laboratorio y flujo de trabajo.

## Uso de GitHub Copilot
Se utilizó GitHub Copilot como asistente predictivo para autocompletar dependencias, librerías de Machine Learning y la estructura de la función de recomendación.
